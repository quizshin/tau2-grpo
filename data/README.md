# Frozen experiment inputs

These inputs are committed for handoff at the user's request. They are benchmark/synthetic task data, not live customer records. Models, checkpoints, credentials and rollout outputs are not included. Do not apply the repository's code license to third-party data; retain and consult the upstream data terms.

## Source and contents

- Raw source: [inclusionAI/AReaL-tau2-data](https://huggingface.co/datasets/inclusionAI/AReaL-tau2-data/tree/86971dc03da6e7c1a7933295e05b84aab8215386), pinned revision `86971dc03da6e7c1a7933295e05b84aab8215386`. Consult its dataset card for licensing and provenance.
- `raw/areal_tau2/`: original `tau2_rl_train.jsonl` and nine database files (Airline, Retail and Telecom). Original bytes preserved.
- `manifests/`: frozen Airline train200 / selection60 / reserve888 and seed42 split metadata.
- `sft/`: server's actual SFT train45 / validation5 inputs and split metadata. The train input SHA256 is `e0aec9fb93c25f4f63e6580f6cdfcc0b95c1dfabe47bdf284745fa1759d1384b`, matching the input previously audited for `new-off`. This is not the older audit snapshot with hash `a930dbff...`.
- `../results/analysis/rl_curriculum_20260912/manifests/`: 40-task curriculum plus sidecar.
- `../results/analysis/rl_curriculum50_20260912/manifests/`: current 50-task curriculum plus sidecar. Existing paths are retained so current configs resolve without edits.

On 2026-09-12, all 17 raw/base-split/SFT files were compared byte-for-byte by SHA256 with `/root/autodl-fs/tau3-core-20260912/code/data` on the training server. The two curriculum task pools retain their verified 40/50 hashes. `SHA256SUMS.json` lists repository-relative paths, sizes, and hashes for all 21 data files, including sidecars.

## Verify after cloning

Run from the repository root:

```bash
python3 - <<'PY'
import hashlib, json
from pathlib import Path
for name, info in json.loads(Path('data/SHA256SUMS.json').read_text()).items():
    p = Path(name)
    assert p.stat().st_size == info['bytes'], name
    assert hashlib.sha256(p.read_bytes()).hexdigest() == info['sha256'], name
print('All frozen data hashes match.')
PY
```

Train, selection and reserve are distinct splits. The current 50-task pool is a subset of train200; selection60 is for internal evaluation and must not enter gradient updates. These checks verify data identity and task-ID separation, not full semantic decontamination or reward correctness. Official final50 remains reserved for the locked-model final evaluation.

Parquet files are generated by the preparation scripts; their absence is intentional. Read [the current experiment](../docs/CURRENT_EXPERIMENT.md) before launching. Download/prepare models and the Linux GPU environment separately.
