# 三模型 selection60 评测与中断修复结论

2026-09-26，北京时间。Base、SFT 1 epoch、SFT 3 epoch 各60条，trial0、seed42。原始对话180/180完成；评分技术异常已完成复核，178条有效评分，2条真实模拟器偏离保留未评分。因而本轮是**采样和异常审计完成，完整三模型统计比较未成立**。

## 双指标

|模型|完整对话|有效评分|严格成功数|等价成功数|完整集合严格率|完整集合等价率|
|---|---:|---:|---:|---:|---:|---:|
|Base|60|60|20|23|33.33%|38.33%|
|SFT 1 epoch|60|59|18|19|不可用|不可用|
|SFT 3 epoch|60|59|19|19|不可用|不可用|

“严格”要求参考终态与合规；“等价”接受事先登记的合法等价终态，同时要求相同合规条件。两者均不是单纯工具顺序匹配，也不是judge印象分。Base多出的3个等价成功是458、728、923；SFT1多出的1个是728；SFT3没有额外等价成功。

未评分不算0，也不从分母删除。只作算术界限：SFT1严格成功可能在18–19/60（30.00%–31.67%），等价19–20/60（31.67%–33.33%）；SFT3两项均19–20/60。**这些是未知项取0或1得到的界限，不是正式成绩或置信区间。** 两个SFT的等价成功上界仍低于本轮Base的23/60，本次没有显示出SFT提点；不能据单个seed宣称稳定退化或认定因果。

已知配对变化：SFT1相对Base等价成功新增6题、丢失10题、1题未知；SFT3新增8题、丢失12题、1题未知。未取59题交集重新算成功率，未输出不完整样本的配对置信区间。协议对照无不一致、无缺失身份字段；比较被阻断的原因是两条未评分。

## 两条无法在原协议中修成有效模型分数的对话

- **SFT1 / airline_363**：场景要求在移除乘客被拒后提出basic economy目标，但模拟用户始终未提出该目标，接受business后结束。保留模拟器偏离，不能归为模型漏做一个从未被告知的目标。
- **SFT3 / airline_740**：固定支付偏好是`credit_card_7726435`，模型中性列出两张卡后，模拟用户主动选择`credit_card_2015111`，模型据此执行。不能为了匹配参考答案改写用户选择，也不能硬判模型0分。

两题完整原文、原始judge响应与复核证据均保存。不是等待程序重试的临时故障。要获得全量可比较的新成绩，需要另立模拟器协议；旧对话不能通过重采样替换而伪装成同一次完整评测。

## 失败暴露的问题

以下为已评分部分涉及该类失败的独立题数，可重叠，且未经全量独立人工标注。

|失败类别|Base|SFT1|SFT3|

典型证据包括：SFT3_1059把应退7083美元解释成144美元；SFT3_657把18小时50分判断为超过24小时；SFT1_651/864与SFT3_1106在用户询问行李额度/价格后立即写入，解释与确认顺序不符合冻结要求；SFT1_336在用户仅说生日在账户中的情况下未查询就填入生日。单纯增加epoch未修复这些决策问题。

金额标签减少不等于整个任务成功提升：SFT1同时丢失了其他原本成功的任务。目标、金额计算、价格披露和用户确认应在同一段完整轨迹中连贯训练。原AReaL候选的组合报价也需区分：源对话77的+55/-13组合净额+42已正确报价，不能把缺少单笔金额简单标成算错；本轮逐笔披露规则不在看分后放宽。

## 使用限制与下一步

这是修复过、且校准样本已经暴露的selection开发评测。13条校准对话不是盲测金标；例外由Codex按证据复核，不是独立人工评审。没有对178条自动有效响应做全量语义人工认证。因此不能把它当成官方final50成绩，也不能与旧的60×4成功率直接比较。

下一轮先用独立训练场景验证模拟器是否稳定传达固定支付偏好和后续目标，再冻结统一协议。对评分器应补缺字段/证据类型的确定性校验及独立标注校准；不要让模拟器获得参考动作或替模型算答案。数据侧优先补历史价格与新报价、多人数净额、24小时边界、先说明再确认、缺字段先查询的完整交互，再检查训练/验证来源隔离。149条候选仍需按这些门槛复核后形成独立训练计划；本轮未启动新训练。
