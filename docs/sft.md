# 三阶段 SFT

|阶段|累计对话|重点|
|---|---:|---|
|A|109|工具选择、证据、参数与收尾|
|B|393|保留A，增加多约束、费用、确认和政策|
|C|500|保留A/B，增加多步状态、重规划和完成|

阶段之间继续训练前阶段选定checkpoint，不能每阶段默认为重新从基座训练。dev37已验收；扩展dev150需要候选生成、审核和冻结，不能把候选数量当作有效集。

公共实现为 `tau3_grpo.training.sft.train`，入口为 `scripts/train/sft/run.sh`。已有 `configs/train/sft/qwen35_lora.yaml` 提供双A800基础配置；课程500/37资产、A/B/C预算、阶段选择规则和续训/导出路径必须在实际实验配置中明确。旧A100/repair配置不等于A109/B393/C500配置。

本次是仓库范围整理，未编造三阶段训练完成状态，也未以任意epoch/学习率创建“已验证”配方。完整课程对照和每阶段导出仍需执行前冻结。监督模板说明见 [thinking与mask](sft_thinking.md)。
