日期：2026-09-20。状态：`diagnostic_only_not_frozen`。用户授权范围为新增奖励版本及旧轨迹 CPU 对照，无新采样、GPU、模型推理、权重拟合或正式训练。

## 修改与假设

新增独立 `paper_env_split_v4`。固定 Airline 基准中 `transfer_to_human_agents` 是不写库的 GENERIC 工具。成功调用统一进入 `generic=0`，包括精确参考、摘要不同、部分匹配及重复调用；仍保留精确匹配索引、执行参数与重复证据，不将这些证据当作授权或语义正确性判断。执行错误保持 `error`，未知工具仍为 `unknown`，`calculate` 沿用中性读取类别。

新版本不允许覆盖或拟合 generic 权重。数据库写工具继续使用原匹配及奖励；`state_change` 表示未命中参考的数据库写工具调用，不保证实际产生 DB 差异，也不证明行为违规。旧版本、官方终局、Hybrid gamma=0.9/lambda=0.3、过滤与任务调度保持原义。

接通评分、veRL 分类 telemetry、IRC CLI/配方校验、正式 runner 和组件配置。正式运行仍要求通过的冻结配方，本次没有生成冻结配方。新增 YAML 中的默认权重是初始化值；本次对照明确使用旧候选报告里的固定权重，不能把默认 YAML 当成已校准配方。
