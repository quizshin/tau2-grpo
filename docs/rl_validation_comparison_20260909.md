## 全参数概率计算的显存修复

RL-006 仍在同一 log-softmax 处 OOM（需 15.16 GiB，仅余 4.13 GiB），没有完成更新。`logprobs_from_logits_v2` 的低精度分支原先按 batch 行处理，但一行仍包含完整序列和词表；CUDA autocast 又会将 log-softmax 升为 FP32，造成大型临时副本。

RL-007 把无梯度、三维低精度 logits 的处理改为每 128 个 token 一块，保留每个 token 的完整词表、原运算及 autocast 行为。训练 autograd 路径保持原样，不缩短任务或 token 预算。LoRA RL-005 运行早于这一显存修复，不能声称两者源码逐字相同。

本地相关回归 103 passed（35.00 秒），远程 100 passed / 3 skipped（61.07 秒）；跳过项是本轮未使用的 Qwen3.5-9B / Qwen2.5-7B tokenizer 资产检查。CUDA BF16/FP16、有/无 autocast 四组输出均逐元素一致。形状 1×1024×16384 的 BF16 autocast 探针，临时 allocated 峰值从 128 MiB 降至约 24 MiB；这是受控探针，不是整轮训练峰值。RL-007 已在真实 full 训练中通过此前失败的概率计算阶段。

RL-007 已通过首批真实 ref log-prob 计算，两份 log-prob 全部有限；第一批官方成功 3/8，`airline_1072` 为全零组，`airline_709` 为 3 成功 / 1 失败，优势范围 [-1.499997, 0.499999]。第 1 步完成，梯度范数 5.187434673，actor 更新 262.3465 秒，整步 473.1123 秒。保存模型覆盖全部 473 个基座张量：320 个语言张量变化，153 个视觉张量完全不变；630,012,366 个 FP32 元素变化，其中 19,059,203 个在转为 BF16 后仍有差异；所有值有限，额外 lm_head 与输入 embedding 完全相同。该审计不等于对 full vLLM 所有转换后张量完成逐项 hash 核对。[RL-007 SwanLab](https://swanlab.cn/@quizshin/tau3-grpo-pytrio/runs/llml3h9i)。
