# 运行维护

每次运行使用独立results/runs目录，保存提交、dirty补丁、实际配置、模型/数据身份、日志和回执。模型、环境、数据和检查点独立于Git源码管理。

正式RL默认每10步保存完整恢复状态，验证新checkpoint各rank文件后再轮换旧checkpoint。主动停止完成下个整十边界的更新、保存、评测与记录；故障停止不能标作完成。完整恢复不等于仅模型权重可加载。

同一实验续训沿用原SwanLab run及真实step，先核对检查点与云端步数。协议或算法变化新建明确实验，不覆盖旧结果。详见 [SwanLab](swanlab.md)。

活动训练、评测或数据任务运行时不覆盖checkout。部署前检查HEAD、未提交改动和进程，部署后核对文件内容。不要因为GitHub已更新就假定服务器同步。

本次公开版精简没有修改用户既有本地code和服务器目录；旧部署仍可按旧提交复现。
