# split v4 与论文差异，以及校准到训练的路径

2026-09-20。依据本地 arXiv:2604.02869v1 PDF 的 §3.2 Eq.(2)、§4 Algorithm 1、Table 4、§5、Appendix A，以及当前代码。已提取全文并查看相关完整页面。本轮不修改生产算法、不启动 GPU。

## 结论

`paper_env_split_v4` 是最新的项目环境适配变体，不是论文配方原样复现。优势主公式与论文一致，奖励类别、权重拟合范围、参数比较及实验条件不同。当前正式入口的冻结配方要求是项目约定，不能解释成论文禁止任何未校准探索性训练。

|项目|论文描述|项目 split v4|
|---|---|---|
|Hybrid|折扣过程回报加折扣终局后组内归一化，再加 lambda×终局优势；gamma=.9/lambda=.3|相同主公式，同任务同轮次分组；ddof=0、缺失轮不参与是显式实现约定|
|参考动作|精确匹配奖励1；包含参考查询，未限定数据库写入|拆 gold_read/gold_write；gold_read固定0，仅gold_write拟合正权重|
|软匹配|附录0.5+0.5×参数重合比例；Table 4保留0.5+|soft_match固定0|
|重复调用|§4.1列出-0.2，最终每个版本完整配方未公开|duplicate固定0|
|转人工|附录列在state-changing工具中，具体分类仍受gold/soft等优先级影响|成功转人工强制generic=0；执行错误仍进入error|
|参数比较|递归去空值、数字字符串转换、字典列表排序|按固定环境实际消费的参数转换比较，保留ID/列表顺序语义|
|IRC调权|Algorithm 1遍历类别，相关性超过delta时r=alpha*rho，否则0|仅拟合gold_write/error/state_change，其他类别显式固定中性|
|验收|类别平均GN(即时奖励)+lambda×GN(终局)方向；奖励均值与终局相关性超过eta|增加实际Hybrid方向、40/10任务划分、两侧min_support=20及身份/重放/冻结检查|
|训练评测|4B从原始模型出发；Tau1训练/Tau2评测；DeepSeek-V3训练用户、GPT-4.1评测用户；每题4条，训练温度.9|从项目SFT new-off出发；项目train50/selection60；Qwen3.8用户模拟器；每组8条，20step基准|

论文的 alpha/delta/eta 具体值、min_support=20、20%留出以及双重方向门槛，不能混为作者公布的同一套要求。正文/Table 4的“保留gold=1、error=-.1”等实例也不能由伪代码唯一推导成每个最终实验的完整冻结配方。此处未确认存在可核验的作者发布代码。

论文检查类别平均方向，不保证每个错误轮的总优势必负；即时奖励0也不保证包含未来回报的Hybrid优势0。项目不得把这些更强性质当作论文承诺。

## 建议执行路径

目标维持“最新适配v4”，不增加局部错误惩罚新算法，也不把所有错误优势强制裁负。

1. 接通一个仅收集轨迹的校准入口。固定SFT new-off，使用训练执行链路、用户模拟器、温度与预算；完整覆盖train50；DF off；不更新策略、不读selection/final。既有 `env_info/a800_20260919/architecture_acceptance.py` 的val_only路径已经验证过真实无更新采样，但只有2任务×2条；尚无可直接运行的完整train50 IRC采样CLI。需要扩展该能力并验证分组、真实token span、process记录进入校准器的适配。不能简单把独立评测输出冒充训练buffer或虚构旧logprob/mask。
2. 建议首批50任务×8条=400条，固定40/10任务划分。它是覆盖与发生率检查，不保证稀有类别两侧达到20；采样前需单独确认GPU预算。初始化奖励只用于记账，不更新权重，因此不需要先有通过的正式配方才能采样。
3. 在拟合侧按既有IRC估计三类权重，留出侧只验收；保留原完整组与scored状态。若支持不足，依据新数据估计追加成本并限定下一批预算；不能为了达20无限采样，也不能把历史与新buffer偷偷混成独立证据。若支持足够仍方向不符，明确报告未通过并检查类别/同轮聚合，而不是继续用相同数据反复调到通过。
4. 通过后由校准器生成frozen-recipe.json，先做正式入口dry-run，再从共同SFT起点运行20step、8×8/step、1,280候选、DF off。校准采样单独计成本，不计入1,280训练候选；每10step保存/评测，末尾独立评测使用与GRPO相同协议。训练、评测温度等必须显式保存，不能沿用正在变更的默认值。

正式训练现成入口（仅示意，路径必须替换为真正通过的新配方和新目录；本轮未执行）：

```bash
python scripts/train/rl/run_mt_gtpo_formal.py \
  --reward-version paper_env_split_v4 \
  --reward-recipe /absolute/path/to/passed/frozen-recipe.json \
  --result-dir /absolute/path/to/new-v4-run \
  --updates 20
```

若用户选择先用本轮候选权重做探索性短程训练，可以另设明确实验入口和预算，保留未通过标记；这不是“IRC已收敛”，不能绕过旧正式入口后冒充校准成功。

最小剩余工程是专用无更新采样入口和格式桥接，不是重新实现MT-GTPO。GPU采样、训练和预算需另行确定；本报告没有授权或启动这些操作。
