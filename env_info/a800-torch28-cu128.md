# A800 training contract

Required base image:

- Python 3.12
- PyTorch 2.8
- CUDA 12.8
- vLLM 0.10.2 (officially pinned to Torch 2.8.0)
- Transformers 4.56.1
- OpenCV headless 4.11.0.86 (the latest line compatible with veRL's NumPy <2)
- CuPy CUDA 12.x 13.6.0 (the NumPy <2-compatible Ray/vLLM line)
- SciPy 1.14.1 (Python 3.12 and NumPy 1.x-compatible wheel)

`setup.sh a800` uses the Aliyun PyPI mirror by default. Override it only when
needed with `TAU3_PIP_INDEX_URL`.
- 8 × A800 for the full plan; a single A800 is enough for installation and
  one-trajectory smoke tests.

The 8-GPU topology reserves GPU 0–5 for veRL policy training/rollout and GPU
6–7 for the OpenAI-compatible user-simulator endpoint.

Preflight:

```bash
nvidia-smi
python - <<'PY'
import torch
print(torch.__version__, torch.version.cuda, torch.cuda.device_count())
assert torch.__version__.startswith("2.8")
assert torch.version.cuda == "12.8"
PY
bash setup.sh a800
bash scripts/maintenance/check_installation.sh
```

On AutoFS/FUSE data volumes, keep caches and models on the data disk but place
the small-file-heavy virtual environment on the local root volume:

```bash
TAU3_VENV_DIR=/root/tau3-venv-a800 bash setup.sh a800
source /root/tau3-venv-a800/bin/activate
```
